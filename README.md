# أجرلي — خطة التطوير صيف 2026

## Description
Ajrli Development Plan is an interactive, single-page presentation built for "أجرلي" (Ajrli), a Libyan property rental app targeting a summer 2026 launch. Designed as a fully front-end slide deck with a dark ocean and cyan theme, it walks through the app's marketing strategy, challenges and solutions, engagement plan, and future vision — all in a smooth, animated, RTL Arabic interface. The project demonstrates practical front-end skills, including custom CSS animations, responsive grid layouts, and vanilla JavaScript slide navigation.

## Features

* 7 fully animated presentation slides with smooth transitions
* Keyboard navigation (arrow keys, space bar) and touch/swipe support
* Progress bar, slide counter, and clickable navigation dots
* Custom dark ocean theme with cyan accents and noise texture overlay
* Fully responsive layout using vw/vh and clamp() for all screen sizes
* RTL Arabic interface with Cairo and Tajawal fonts

## How to Use

1. Use the live demo bellow 
2. Navigate slides using the arrow buttons, keyboard, or swipe gestures
3. Use the navigation dots at the bottom to jump to any slide directly
4. Fully static — no setup or server required
